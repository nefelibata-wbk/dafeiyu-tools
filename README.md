# B站视频抽帧工具（bilibili-video-kit）

给一条 BV 号，自动把视频拆成**能读的东西**：按画面变化选出的分镜图 +（可选）字幕。

> ⚠️ 先说清楚：**这是一个 Python 脚本，不是一个"装上就能用的插件"。**
> 没有双击运行的 exe，要先装 Python 和 ffmpeg，再改一个配置文件里的路径。
> 下面三步（再加一步建议）照着做，十分钟内能跑起来。

---

## 零、开始之前，先看看这些条件你齐不齐

**这一段请务必看完再看代码。** 缺任何一项，脚本都会跑不起来或者效果打折。

| # | 前置条件 | 必须吗 | 大概要花多久 | 缺了会怎样 |
|---|---|---|---|---|
| 1 | **Python 3.9+** | ✅ 必须 | 装过就跳过，没装约 10 分钟 | 什么都跑不了 |
| 2 | **ffmpeg**（命令行程序） | ✅ 必须 | 下载解压约 5 分钟 | 一抽帧就报错 |
| 3 | **`pip install -r requirements.txt`** | ✅ 必须 | 1 分钟 | 缺 numpy/Pillow 直接崩 |
| 4 | **改 `config.py` 里的两行路径** | ✅ 必须 | 2 分钟 | 找不到 ffmpeg、不知道产物放哪 |
| 5 | **一个 B站账号**（用来登录 Edge） | ⬜ 强烈建议 | 登录一次，30 秒 | **不登录也能跑，但画质被压到 720P 以下、CC 字幕也拿不到** |
| 6 | **Edge 浏览器** | ⬜ 建议 | 一般本来就有 | 没填 `EDGE` 就取不到高清直链，照样只能低清 |
| 7 | faster-whisper + 模型 | ⬜ 可选 | 半小时起 | 没有字幕，只有分镜图 |
| 8 | demucs + PyTorch | ⬜ 可选 | 半小时起 | 人声分离跳过，字幕会混进 BGM 歌词 |

**一句话总结**：1~4 是硬门槛，5~6 决定清晰度，7~8 是锦上添花。

> 💡 **为什么非要 B站账号？** 不是要你的密码——脚本用的是你自己 Edge 里已经登录好的
> B站身份去请求播放地址和字幕。不带登录态，B站只肯给低清，字幕接口也不给数据。
> 脚本只会把你的登录态用在本机请求上，**不会上传、不会外传**。

## 一、它解决什么

你可能遇到过这几种情况：

- 一小时的视频，你只想判断"值不值得看"，却得拖进度条
- 想让 AI 帮你读视频，整片截图几百张，token 直接爆炸
- 按固定间隔抽帧，切点密的片段全漏掉，切点疏的地方抽一堆重复

这个工具做的是：**按镜头切，不按时间切**。画面变的地方多给帧，不变的地方少给帧。

实测（71 秒视频）：

| 做法 | 拼图 | 约合 token |
|---|---|---|
| 固定 1.5 秒抽 47 帧 | 两张 2400 宽大图 | ≈ 18,866 |
| 本工具 · 12 帧 | 一张 | ≈ 1,222 |

**省 93%**，而且变化快的地方反而比固定间隔看得更细。

## 二、装（三步必须 + 一步建议）

### 第 1 步：装 Python 依赖

需要 **Python 3.9 或更高**。在仓库目录下执行：

```bash
pip install -r requirements.txt
```

### 第 2 步：装 ffmpeg

抽帧全靠它，必须先有。

| 系统 | 怎么装 |
|---|---|
| Windows | 到 ffmpeg 官网下 `ffmpeg-release-essentials.zip`，解压到比如 `C:\ffmpeg`，把 `bin` 目录加进 PATH，**或者**直接在 `config.py` 里写 `ffmpeg.exe` 的完整路径 |
| macOS | `brew install ffmpeg` |
| Linux | `sudo apt install ffmpeg` |

验证：终端里敲 `ffmpeg -version`，有版本号输出就行。

### 第 3 步：改 `config.py`

打开 `config.py`，把标着 **「待填写」** 的几行换成你自己的路径。只有前两个是必须的：

```python
FFMPEG = _p("FFMPEG")           # ffmpeg.exe 完整路径；填 "" 则从 PATH 找
OUT    = _p("VIDEO_OUT")        # 产物放在哪，建议 ./data
EDGE        = _p("EDGE")        # 可选：Edge 程序路径（不填取不到高清）
EDGE_PROFILE = _p("EDGE_PROFILE")  # 可选：登录过 B站的 Edge 用户目录
```

> 💡 **不想改文件也行**：所有项都支持环境变量覆盖，变量名写在每行注释里。
> 例如 `set VIDEO_OUT=D:\video-kit\data`。

改完先跑一次检查：

```bash
python -c "import config; config.summary()"
```

会打印一份「配置检查」，哪一项没填一目了然。

### 第 4 步（建议）：给脚本一个登录过 B站的 Edge 目录

高清直链要靠登录态才拿得到。做法：

1. 新建一个空目录，比如 `D:\video-kit\edge-profile`
2. 用这个目录打开一次 Edge（命令行）：

   ```bash
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --user-data-dir="D:\video-kit\edge-profile"
   ```

3. 在这个窗口里**登录你的 B站账号**，然后关掉窗口
4. 把 `config.py` 里的 `EDGE_PROFILE` 填成这个目录

之后每次运行，脚本会复用这个目录里的登录态，取完直链自动关掉浏览器。

> ⚠️ **同一个用户目录不能同时开两个 Edge。** 如果报「调试端口起不来」，
> 先把这个目录的 Edge 全部关掉再跑。

## 三、跑

```bash
python 看视频就用这个.py BV1xx411c7mD
```

常用参数：

| 参数 | 作用 |
|---|---|
| `--no-audio` | 只要画面，别碰声音（默认会顺便抽音轨） |
| `--again` | 这个视频之前跑过，强制重来（默认会拦下，告诉你什么时候看过的） |
| `--page 2` | 多 P 视频看第几 P |
| `--asr large-v3-turbo` | 转写换小模型，快但准确率降 |
| `--hotwords "某某 某某某"` | 专有名词热词，空格分隔 |
| `--mode ppt` | 强制走 PPT/黑板分支（整页变化才算换页） |

产物都在 `OUT/<BV号>/` 下：

```
分镜_切点.jpg        帧数 ≤ 12 时：一张图看完
分镜_分段_01.jpg …   帧数更多时：每张 9 帧，按编号顺序读
字幕.txt             字幕（带时间戳）。优先用 B站 自带 CC 字幕，没有才转写
_src.mp4             下载下来的源片，下次不用重下
```

**读的时候按编号顺序，一张都别落下。** 帧与帧之间接不上，就说明中间丢了东西。

## 四、字幕：三层，从「零安装」到「全自动」

默认会尝试拿字幕，但**从重到轻有三条路，按你的需要选**：

| 方案 | 要装什么 | 覆盖范围 | 什么时候用 |
|---|---|---|---|
| **① B站 CC 字幕**（默认先试） | **什么都不用**，只要 `EDGE_PROFILE` 是登录态 | UP 主传了字幕、或 B站 有 AI 字幕的视频 | 默认就是它，能拿到就到此为止 |
| ② whisper 转写 | `pip install faster-whisper` + 一个模型 | 有声音就能转，100% | CC 字幕没有、但视频是讲解类 |
| ③ 人声分离（辅助 ②） | `pip install demucs soundfile` + PyTorch | —— | BGM 很吵、转写把歌词也抄进去了 |

有 NVIDIA 显卡会快很多，没有也能跑（脚本自动退到 CPU，只是慢）。

> 💡 **别一上来就装 whisper。** 大多数视频 B站 自带字幕，第 ① 条就够，
> 而且那是 UP 主自己写的，比机器听写准得多。等真的遇到"没有字幕"的片子再装。

有 NVIDIA 显卡会快很多，没有也能跑（自动退到 CPU，只是慢）。

模型从 huggingface 国内基本下不动，建议用 ModelScope 镜像，下好按这样放：

```
<MODELS_ROOT>/faster-whisper-large-v3/model.bin
```

> 注意：`_separate.py`（人声分离）和 `转写.py` 要**和主脚本放在同一个目录**，主脚本用相对路径调它们。

## 五、常见问题

**Q：跑起来报 `ffmpeg` 找不到 / `FileNotFoundError`**
A：ffmpeg 没装或在 PATH 里找不到。最稳的办法是在 `config.py` 里写死完整路径。

**Q：画面很糊，只有 360P/480P**
A：三个原因，按顺序排查：
1. `EDGE` 没填 → 脚本取不到高清直链；
2. `EDGE_PROFILE` 指向的目录**没登录过 B站** → 只能拿到低清；
3. 该视频本身最高就不高。

  填好 `EDGE_PROFILE` 后，手动用**这个目录**打开一次 Edge、登录 B站，之后脚本会自动复用登录态。

**Q：没生成字幕.txt**
A：先看运行时有没有打印「没配 ASR_PY」或「找不到本地 whisper 模型」。声音部分是可选功能，跳过不影响分镜图。

**Q：Windows 控制台中文乱码**
A：脚本已经把 stdout 设成 UTF-8；如果还乱，`chcp 65001` 一下。

**Q：`websocket-client` 相关报错**
A：`pip install websocket-client`。它只在取高清直链时用得到。

## 六、它是怎么选帧的（想调参再看）

1. **基准铺底**：按片长均匀取点，最长 10 秒一个
2. **二分补帧**：相邻两帧差别大于阈值，就在中间再取一帧，递归到最小粒度
3. **合并相似**：几乎没变的相邻帧合成一帧（**每帧最多合并一次**，防止连锁合并一路删下去）

两个模式自动切换：

- **普通片**：看「分块最大差」（4×4 里变化最大那块），局部动作也算变化
- **PPT/黑板**：看「16 格中位数」，讲师走动会被忽略，只有整页换掉才算变化

阈值都在命令行里，默认值经过标定，一般不用动。

> 🔴 一个贯穿全项目的取舍：**宁可多留几帧，不可漏掉一段。**
> 多一张图的代价是几十个 token，漏一段的代价是得出一个错的结论。

## 七、已知限制

- 只支持 B站（其他站点需要换 `bilibili.py` 里取直链那段）
- 依赖 Edge 的调试端口取高清，Chrome 需要改配置；不填就只能低清
- 未登录时画质会被压，且**不会报错**，只会静默降级（日志里有一行提示）
- 抽帧只会「按画面变化」，**看不懂内容**——它不告诉你视频讲了什么，只告诉你该看哪几帧
- **CC 字幕不是人人都有**：UP 主没传、B站也没生成 AI 字幕的片子，这一层就是空的；
  这时要么装 whisper 自己转，要么只看图
- 字幕接口和播放接口一样是**非公开接口**，B站改规则就可能失效（到时候会静默跳过，不会崩）
- 快剪（平均镜头 < 1 秒）的片子帧数会比较多，这是有意的
